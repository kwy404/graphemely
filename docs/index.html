Issue No.04

How it works

Segment first, then count and cut

  1. Step 1

    Segment

    Text is split into grapheme clusters with Intl.Segmenter, or a built-in Unicode UAX #29 fallback where it is missing.

  2. Step 2

    Count and cut

    Lengths and indices refer to clusters, so a flag, a skin tone or an accented letter is always one unit.

  3. Step 3

    Return whole text

    Every result is made of complete characters: no lone surrogates, no detached accents, no half emoji.

A string is not a list of characters. It is a list of UTF-16 code units that sometimes happen to be characters.

Issue No.09

Letters to the editor

Questions

What is a grapheme cluster?

The Unicode name for a character as a person sees it: one or more code points shown as a single unit, such as a letter with an accent, a flag or an emoji with a skin tone.

Why does an emoji have length 2 in JavaScript?

JavaScript strings are UTF-16. Most emoji live outside the Basic Multilingual Plane and take a surrogate pair of two code units, and .length counts code units. Sequences such as families and flags take even more.

How is graphemely different from Intl.Segmenter?

graphemely uses Intl.Segmenter when it exists and adds the operations you actually need on top of it: length, slice, at, truncate with ellipsis and word boundaries, reverse, pad and wrap, plus a Unicode fallback for runtimes without it.

Does truncate count the ellipsis?

Yes. truncate(str, 10) returns at most 10 visible characters including the ellipsis, so the result always fits the space you have.

Does it work with TypeScript, CommonJS, Deno and Bun?

Yes. The package ships ESM and CommonJS builds with TypeScript types, has zero dependencies and runs in Node 16 and newer, every modern browser, Deno and Bun.

Browser and runtime support

graphemely uses Intl.Segmenter in Node 16+, Chrome and Edge 87+, Safari 14.1+, Firefox 125+, Deno and Bun, and a built-in Unicode UAX #29 fallback everywhere else. Output is ES2020.
