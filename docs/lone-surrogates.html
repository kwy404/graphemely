Guide No. 04 / Surrogates

Lone surrogates

A lone surrogate is half of an emoji (or any character outside the Basic Multilingual Plane) left behind when a string is cut by code unit. Detect it with isWellFormed(str) and replace it with U+FFFD using toWellFormed(str).

By Alexandre KohlerUpdated 15 October 20262 min read

The fix, copy and paste

Emoji in the code samples are written as JavaScript escapes, for example \u{1F468} for a man. In your own code you can type the emoji directly.

Why lone surrogates are a problem

  • encodeURIComponent throws URIError: URI malformed.
  • TextEncoder and most UTF-8 encoders silently replace them with U+FFFD, so data changes on its way to a server.
  • Some APIs and databases reject the request as invalid UTF-8.
  • They render as a replacement box or a question mark in a diamond.

Where they come from

Almost always from cutting text with code unit indices: str.slice(0, n), str.substring, str[i], str.split('') or a maximum length enforced by an input field. The real fix is to cut by grapheme cluster with truncate or slice, so they never appear. toWellFormed is the safety net for data that is already broken.

Native methods

ES2024 added String.prototype.isWellFormed and toWellFormed. They are missing on Node 18 and older browsers. The graphemely versions behave the same and work everywhere.

Half an emoji is not a smaller emoji. It is invalid text.

Install

Works in Node 16 and newer, all modern browsers, Deno and Bun. ESM and CommonJS, TypeScript types included, zero dependencies, about 2 kB gzipped. Try your own text in the Text Lab.
