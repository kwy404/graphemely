How to reverse a string with emoji in JavaScript

The classic str.split('').reverse().join('') turns every emoji into broken halves. Reverse by grapheme cluster instead with reverse(str) from graphemely.

The fix, copy and paste

Emoji in the code samples are written as JavaScript escapes, for example \u{1F468} for a man. In your own code you can type the emoji directly.

Why the usual one liners break

Broken: code units
Still broken: code points

The spread version keeps surrogate pairs together, so it looks right for simple emoji. It still reverses the inside of multi code point sequences: flags turn into different flags or into two letters in boxes, a skin tone modifier moves in front of its emoji, a combining accent jumps to the previous letter, and family emoji fall apart into single people.

Install

Works in Node 16 and newer, all modern browsers, Deno and Bun. ESM and CommonJS, TypeScript types included, zero dependencies, about 2 kB gzipped. Try your own text in the playground.

FAQ

split('') splits a string into UTF-16 code units. Reversing them puts the low surrogate before the high surrogate, which leaves two lone surrogates that render as broken boxes.

Only for text without sequences. It keeps code points together but reverses the parts of flags, skin tones, keycaps, ZWJ emoji and combining accents.

Split it into grapheme clusters and reverse those: reverse(str) from graphemely does exactly that.
