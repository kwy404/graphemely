Guide No. 04 / Split

How to split a string into characters with Unicode support

The split('') method gives you UTF-16 code units and [...str] gives you code points. Neither matches what a person calls a character. graphemes(str) from graphemely splits into grapheme clusters.

By Alexandre KohlerUpdated 13 October 20262 min read

The fix, copy and paste

Emoji in the code samples are written as JavaScript escapes, for example \u{1F468} for a man. In your own code you can type the emoji directly.

Three ways to split, compared

MethodUnitThumbs up with a skin tone becomes
str.split('')UTF-16 code unit4 broken pieces (lone surrogates)
[...str], Array.from(str)Code point2 pieces: thumbs up, then a lone skin tone swatch
graphemes(str)Grapheme cluster1 piece, exactly as displayed

Using Intl.Segmenter directly

Modern runtimes include Intl.Segmenter, and graphemely uses it when it is there. The direct version is:

graphemely adds a fast path for plain ASCII and Latin-1 text, a built-in fallback for runtimes without Intl.Segmenter, and the operations you usually need next: truncate, slice, reverse, pad and wrap.

A character is whatever a person would point at with a finger.

Install

Works in Node 16 and newer, all modern browsers, Deno and Bun. ESM and CommonJS, TypeScript types included, zero dependencies, about 2 kB gzipped. Try your own text in the Text Lab.

FAQ

How do I split a string into an array of characters in JavaScript?

Use graphemes(str) from graphemely, or Intl.Segmenter with granularity grapheme. Avoid split(''), which breaks emoji.

What is the difference between split('') and Array.from(str)?

split('') splits by UTF-16 code unit, so emoji become lone surrogates. Array.from splits by code point, which keeps simple emoji but breaks sequences such as flags and skin tones.

What is a grapheme cluster?

The Unicode name for a user perceived character: one or more code points that display as a single unit, such as a letter with accents, a flag or an emoji sequence.
