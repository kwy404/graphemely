Guide No. 05 / Substring

Why substring breaks emoji, and a Unicode safe substring

The methods substring, substr and slice use UTF-16 code unit indices, so any index that falls inside an emoji cuts it. slice(str, start, end) from graphemely uses grapheme indices, so every cut is safe.

By Alexandre KohlerUpdated 13 October 20262 min read

The fix, copy and paste

Emoji in the code samples are written as JavaScript escapes, for example \u{1F468} for a man. In your own code you can type the emoji directly.

What goes wrong with code unit indices

Broken
Fixed

Indices often come from somewhere else (a cursor position, a search match, a database limit). If they were computed in code units, convert the logic to graphemes end to end, and use isWellFormed to assert that a result has no lone surrogates.

Every index is a cluster index, so every cut lands between characters.

Install

Works in Node 16 and newer, all modern browsers, Deno and Bun. ESM and CommonJS, TypeScript types included, zero dependencies, about 2 kB gzipped. Try your own text in the Text Lab.

FAQ

Why does substring break emoji in JavaScript?

Its indices count UTF-16 code units. An emoji uses two or more code units, so an index can point to the middle of it.

What is the difference between slice, substring and substr?

They differ in how they treat negative and swapped arguments, but all three count UTF-16 code units, so all three can break emoji.

How do I take a substring by visible characters?

Use slice(str, start, end) from graphemely. It has the same contract as String.prototype.slice, including negative indices, but counts grapheme clusters.
